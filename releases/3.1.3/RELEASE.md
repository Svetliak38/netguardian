# NetGuardian 3.1.3 — 2026-11-04

Диагностика, которая видит то, что раньше пропускала: оборванный TLS за открытым
портом, зависшие сокеты браузера и блокировку на стороне сервера.

## Артефакты

| Файл | Размер | Что это |
|---|---|---|
| `NetGuardian-3.1.3-portable-win64.zip` | 8.28 МБ | портативная папка, `NetGuardian.exe` + `_internal` |
| `NetGuardian-3.1.3-singlefile-win64.zip` | 7.96 МБ | один исполняемый файл |

Артефакты не хранятся в репозитории (`.gitignore`), их контрольные суммы — ниже
и в `SHA256SUMS.txt`. Сверка обязательна: расхождение означает подмену.

## Что нового

Полный список — в `CHANGELOG.md`, раздел `[3.1.3]`. Коротко:

- `find_stuck` переписан: два снимка TCP-таблицы, причины `persistent`, `pileup`, `state`;
- `probe_ips`: по 3 рукопожатия TLS на каждый открытый адрес, `ok` / `flaky` / `dead`;
- `403` и `451` больше не считаются успехом — вердикт `waf`;
- закрепление IP из диагностики (`pin` / `unpin`) и команда `probe`;
- три режима доверия: `strict`, `medium`, `soft`; `settings.pin_mode` с валидацией;
- свойства exe и `--version` генерируются из одного источника; сборка падает при расхождении.

## Переиздание 04.11.2026

Релиз пересобран после удаления персональных данных: из дефолтов убраны личный
профиль и подсказка процесса, архив исходников больше не содержит `routes.json` и `legacy\`.
Хеши отличаются от первой публикации — сверяйтесь с тем, что ниже.

## Проверка подлинности

1. Скачать артефакт.
2. Сверить SHA-256 с `SHA256SUMS.txt` в этом каталоге:
   `certutil -hashfile <файл> SHA256` (Windows) или `sha256sum <файл>`.
3. Сверить хеши документов: `CHANGELOG.md`, `README.md`, `README.en.md`, `SIGNING.txt`,
   `docs/*` — они перечислены там же.

## Приёмка

- 165 автотестов (`python -m unittest discover -s tests -t .`);
- прогон на живом кейсе: `probe www.bybit.com` — все адреса `TLS 3/3`, вердикт «маршрут исправен»;
- `--version` и `FileVersion` exe совпадают: `3.1.3` / `3.1.3.0`.
