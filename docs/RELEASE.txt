2.5. Готовый комплект
---------------------
Папка NetGuardian-3.1.1-release содержит:
  - три архива (portable, singlefile, source);
  - SHA256SUMS.txt;
  - README.txt, README.en.md, README.en.txt, README.md,
    CHANGELOG.md, LICENSE, NOTICE.txt;
  - docs\PROJECT.txt, docs\HOW-IT-WORKS.txt, docs\RELEASE.txt,
    docs\REVIEW.md.

Эту папку можно скопировать целиком и передать заказчику или
преподавателю без дополнительной сборки.

Имена архивов содержат полную версию (NetGuardian-3.1.1-*.zip) и
формируются build.ps1 из netguardian\__init__.py, поэтому номер в
названии файла всегда совпадает с номером внутри программы. Проверить
совпадение можно командой "NetGuardian.exe --version".

4. ПРОВЕРКА ПЕРЕД ВЫДАЧЕЙ
--------------------------------------------------------------------------------

4.1. Тесты
----------
    cd <папка проекта>
    python -m unittest discover -s tests -t .

  Ожидаемо: "Ran 91 tests ... OK".

4.2. Сборка
-----------
    .\build.ps1

  Скрипт сам запускает тесты, собирает обе версии, проверяет
  портативный exe и создает архивы с контрольными суммами.

4.3. Проверка exe
-----------------
    .\dist\NetGuardian\NetGuardian.exe --version
    .\dist\NetGuardian\NetGuardian.exe config --check
    .\dist\NetGuardian\NetGuardian.exe status

  Ожидаемо: "NetGuardian 3.1.1", валидная конфигурация, код 0.

4.4. Проверка hosts (осторожно)
-------------------------------
    .\dist\NetGuardian\NetGuardian.exe apply <профиль> --dry-run
    .\dist\NetGuardian\NetGuardian.exe cleanup --all --dry-run

  Эти команды ничего не пишут. Реальную запись выполняйте только
  от администратора и осознанно.

4.5. Контрольные суммы
----------------------
    Get-FileHash .\dist\NetGuardian-3.1.1-portable-win64.zip -Algorithm SHA256
    Get-Content .\dist\SHA256SUMS.txt

  Значения должны совпасть.

--------------------------------------------------------------------------------

  - Windows 10/11 x64 (Windows Server 2012+).

--------------------------------------------------------------------------------
6. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
--------------------------------------------------------------------------------

  1. Exe не подписан коммерческим сертификатом. SmartScreen может
     предупредить; контрольные суммы приложены.
  2. Однофайловая версия требует записи в %TEMP%. Если %TEMP% ограничен,
     используйте портативную версию.
  3. Закрепляются только IPv4-адреса.
  4. Браузеры с DoH (Secure DNS) могут игнорировать hosts.
  5. Адреса CDN меняются; фикс не является вечным.
  6. Автообновления и установщика нет: обновление — замена папки.
  7. Программа не заменяет VPN и не обходит блокировки.
  8. Нет подписи и нет автоматической отправки отчетов об ошибках;
     диагностика локальная (diag, logs).
